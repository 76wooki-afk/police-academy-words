# 🎓 경찰대학교 기출 영단어 학습

경찰대학교 입시를 준비하는 수험생을 위한 **3D 플래시 카드 학습 도구**입니다.

## 🚀 바로 시작하기

**웹 링크:** https://76wooki-afk.github.io/police-academy-words/

인터넷 브라우저만 있으면 **어디서나 언제든지** 실행 가능합니다!

## ✨ 주요 기능

### 1️⃣ 3D 플래시 카드
- 단어 카드를 클릭하면 **부드럽게 뒤집혀** 뜻이 보입니다
- 각 단어마다 **실제 사용 예시문장** 포함
- 모든 150개 단어를 한눈에 스크롤하며 학습 가능

### 2️⃣ 미니 퀴즈
- 영단어를 보고 **4지선다형으로 뜻을 맞추기**
- 무작위 순서로 출제되어 **체계적인 학습**
- 정답 및 오답 후 예시문장 표시
- 정답률 통계로 학습 진도 확인

### 3️⃣ 깔끔한 디자인
- 눈이 편한 **보라색 그라데이션 테마**
- 모바일/태블릿/PC **모두 최적화**
- 공부에 집중할 수 있도록 심플한 인터페이스

## 📚 수록 단어

경찰대학교 **10년 기출 고난도 영단어 150개** 수록

**예시:**
- ephemeral (일시적인)
- ubiquitous (어디나 있는)
- perspicacious (통찰력 있는)
- obfuscate (혼란스럽게 하다)
- ... 총 150개

## 💡 사용 팁

1. **플래시 카드 탭**: 단어와 뜻을 암기하며 학습
2. **미니 퀴즈 탭**: 학습한 내용을 검증하고 복습
3. 매일 **10-15분씩** 꾸준히 학습하면 효과적입니다
